# Does the evidence rule reach the file?

**Status:** two sessions pointing opposite ways.

## What it would settle

F6. Whether a limitation named in conversation makes it into the document that travels.

## Evidence in hand

- `evidence-1`: the denominator limitation written into the circulating email, with its
  consequence named, before any number existed to be misread. The good case.
- `story-2`: the agent said it could not verify the memo's opening premise, proposed a
  softening — and the memo went out asserting it as fact.

Different testers. Nothing distinguishes them except which one worked.

## What is missing

A run where the agent flags an unverifiable claim in chat and then produces an artefact
containing it. Check whether the hedge survives the transition.

## What would make it fail

Asking for the artefact in the same turn as the flag. The interesting case is the one where
the flag happens first and the file comes later, which is when it gets dropped.

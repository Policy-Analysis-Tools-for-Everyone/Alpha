# Prompts

Tests the evidence is asking for. Each states what it would settle, what is already in hand,
what is missing, and what would make it worthless.

A prompt earns a file when a transcript turns up something with nowhere to go: a behaviour
seen twice that nobody has tried to break, a defect with a plausible mechanism and no case, a
question two sessions answer differently.

**Not a backlog.** Nothing here is owed. A prompt nobody runs in six months was probably never
a test.

Blunt, like the rest of the wiki. A prompt written to spec standard is a test case, and then
nobody writes the test case.

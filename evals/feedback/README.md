# Feedback

Testers' own accounts, in their words. No transcript.

`../README.md` says testers are not expected to write anything up — the debrief is five
questions and about three minutes. Most contributions will look like this, so they need a home
that is not `../transcripts/`.

**Weaker than a transcript and not nothing.** A note reports what the tester noticed, which is
the only route to behaviour nobody thought to look for. `F12` exists because one tester
mentioned a capability under-firing in passing; no transcript in the repository would have
shown it, because none put that capability in that position.

**Never cite a note for what the agent said.** It is evidence about the tester's experience.
Quote it as a report, and if it turns into a finding, say in `../wiki/findings.md` that the
session is uncommitted.

Anonymise to the tester ID before committing, same as everything else.

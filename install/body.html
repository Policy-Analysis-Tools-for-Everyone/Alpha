Install

Install policymemo.ai

Choose the AI tool you use. You set it up once, on a computer, and it takes between 2 and 10 minutes.

Claude

This is the main version of policymemo.ai, and the one with the most testing behind it.

What you need

  • Claude on a computer: in your browser at claude.ai, or the Claude desktop app.
  • Code execution switched on. Open Settings, then Capabilities. It is on by default for most people. If it is off, policymemo.ai installs and then appears to do nothing.
  • A paid plan (Pro, Max, Team or Enterprise) to install it as one plugin. On the free plan you add the 10 skills one at a time instead.

Install it

Download for Claude

One zip. Leave it zipped: Claude wants the file exactly as it arrives. If you end up with a folder instead, see If it goes wrong.

  1. In Claude, open Customize, then Plugins.
  2. Click Add, then Upload local plugin.
  3. Drag the zip in, or browse to it, and click Upload.
  4. Wait for the security scan to finish, then switch it on. Claude warns that it cannot verify add-ons made by other people. That is correct, and it appears for everything of this kind. Everything policymemo.ai contains is readable in the skills folder on GitHub.
  5. Start a new chat.
Want updates to arrive on their own?

A zip install stays at the version you downloaded. To get updates automatically, add policymemo.ai as a marketplace instead of uploading the zip:

  1. In Customize, then Plugins, click + next to Personal plugins, then Add marketplace.
  2. Paste this and click Sync: Policy-Analysis-Tools-for-Everyone/Alpha
  3. Click Install next to policymemo.ai, then start a new chat.

Plugins need a paid plan, but skills do not. Once all 10 are in, policymemo.ai behaves the same. It takes about 10 minutes.

  1. In Claude, open Customize, then Skills.
  2. Click +, then Create skill, and upload a file from the list below. Do not unzip it.
  3. Check it is switched on, then repeat for the rest. Start with house-rules. It is the one that makes the others behave. The rest can go in any order. If you only ever add 2, add house-rules and problem.
    • 1. house-rules
    • problem
    • stakeholders
    • evidence
    • options
    • criteria
    • outcomes
    • trade-offs
    • decide
    • story
  4. Start a new chat.

Check it worked

On a paid plan, policymemo.ai is listed under Personal plugins and switched on. On the free plan, all 10 skills are listed under Skills. Nothing appears in your chat window, and nothing is supposed to.

Start a new chat and describe a problem you are working on, the way you would to a colleague. It should ask you a question back before it writes anything.

If it goes wrong

It installed but seems to do nothing

Check code execution is on, in Settings, then Capabilities, and start a new chat. Skills do not load into a chat that was already open.

The marketplace install fails with “Failed to fetch content: 403”

If this happens in the desktop app, try Claude in a browser first. If the browser fails too, upload the zip instead, as in the paid plan steps above. It installs the same plugin by a different route.

I have a folder, not a zip

Safari on a Mac unzips downloads on its own. Claude needs the zip, so put it back: right-click the folder and choose Compress, then upload the new zip. To stop it happening again, open Safari, then Settings, then General, and untick Open “safe” files after downloading. This applies to the free plan files too.

There is no Upload local plugin option

That option needs a paid plan, or it may be switched off by your organisation. Use the free plan route: it works on every plan.

Microsoft 365 Copilot

This builds policymemo.ai as an agent in Copilot Chat. It runs on Microsoft’s models with the same written rules as the Claude version. Expect it to drift from them more, especially over a long conversation.

What you need

  • A work or university Microsoft account with Copilot Chat. The free tier included with most Microsoft 365 accounts is enough. Depending on your account, you add the detailed method as skills, as knowledge files, or not at all. The agent works in every case, with less depth the less it has.
  • Permission to create agents. Open Copilot Chat and look for Create agent (sometimes New agent) in the left-hand panel. If it is not there, your organisation has switched agent creation off and none of this will work. Ask your IT service.
  • No admin rights.
Download for Copilot

Unzip it first, unlike the Claude version. On Windows, right-click the zip and choose Extract All: opening it with a double-click is not enough, because Copilot cannot upload files from inside a zip. On a Mac, double-click it. You get a folder with the files numbered in the order you use them. Inside it, leave the 8 skill zips zipped: Copilot wants those exactly as they are.

Build the agent

  1. Open Copilot Chat and click Create agent.
  2. Copilot opens a chat called Message agent builder, asking you to describe your agent. Press Skip. The chat writes its own version of the agent from your description, and would replace what you paste in below. Skipping takes you to the form where you set everything yourself. If you see tabs instead, choose Configure, not Describe.
  3. Name: policymemo.ai
  4. Description: Works through a public policy problem with you: defines it, tests the evidence, builds and weighs options, decides and writes it up. Challenges weak framing and refuses to invent figures.
  5. Instructions: open 1 Paste into Instructions.txt, select everything, copy and paste it into the box. It is about 7,800 characters, and the limit is 8,000. Scroll to the end of the box to check it pasted whole. The last words should be “is still flagged in any document I produced.” If they are not, clear the box and paste again.
  6. Skills: in the Skills section, upload each of the 8 zip files in the 2 Upload these 8 skills folder, one at a time. Do not unzip them and do not rename them. Skills carry the detailed method for each part of the analysis, and Copilot loads the right one as the work moves on. Trade-offs travels inside policymemo-decide, because Copilot allows 8 skills per agent. No Skills section? Under Knowledge, click Upload files and upload the 10 files in 3 No Skills option - upload these as knowledge instead. No upload option there either? That is normal on some free accounts. Skip this step: the agent works from the instructions alone, with less depth. Do not add web links instead: Copilot searches them through Bing rather than reading them, so they will not carry the method.
  7. Web search: switch it off for now. The Claude version does not search the web unless asked, and keeping them alike makes reports comparable.
  8. Other settings: switch off Create documents, charts and code, Create images and Discourage model knowledge. policymemo.ai writes memos as text in the chat, so it needs neither of the first 2. Discourage model knowledge would limit the agent to the skills and files you added, which hold the method but nothing about your policy area, so it would have nothing to apply the method to. The instructions handle the risk this setting guards against: the agent must label anything it adds from its own knowledge and must never invent a figure.
  9. Starter prompts: add these, title then message.
    • Find the real problemI think we've already jumped to a solution. Help me work out what the actual problem is.
    • Weigh the evidenceWe've got evidence from another country that this worked. How much weight should we put on it?
    • Compare my optionsI've got 3 options and I'm struggling to decide what should count as better.
    • Who's affectedHelp me think about who's affected by this and whose support it needs.
    • Test my draftHere's my draft problem statement. Tell me what's weak about it.
    • Write it upHelp me turn this analysis into a one-page memo for a decision-maker.
  10. Click Create.

Check it worked

Open the agent and try a starter prompt. It should ask you a question back before it writes anything. That is deliberate, the same as the Claude version.

To share it, use Share to send a link to people in your organisation, if your organisation allows it. People outside it need to follow these steps themselves.

If it goes wrong

There is no Create agent button

Your organisation has switched agent creation off. Only your IT service can change that.

The instructions were cut short

Clear the box and paste again, then check the last words are “is still flagged in any document I produced.” The full text fits inside Copilot’s 8,000-character limit.

There is no Skills section, or no Upload files option under Knowledge

What you can add depends on your account and your organisation's settings. Skills are a newer Copilot feature that not every organisation has switched on. Uploading knowledge files needs a paid Microsoft 365 Copilot licence, or an organisation that pays for Copilot by use. Use whichever you have. If you have neither, you have not done anything wrong: skip the step, because the instructions carry the core rules and the agent works from them alone.

Linking to the knowledge files on GitHub does not work as a substitute. Copilot only searches linked sites through Bing, it accepts at most 4 links, and it gets snippets rather than whole files.

It ignores the detailed method

The core rules are in the instructions and always apply. The method for each part of the analysis is in the skills or knowledge files you added. Copilot loads a skill when the work matches it, and searches knowledge files only some of the time. Naming the job usually helps, for example "help me weigh the evidence".

The upload cannot find the files, or will not take them

You are probably looking inside the zip without having unzipped it. Close the upload window, unzip the download as described above, and upload from the folder that appears.

For skills, upload each policymemo- zip file itself. A skill that has been unzipped into a folder will not upload.

policymemo.ai has been updated

Updates are not automatic. Download the new zip, paste the new instructions and replace the skills or knowledge files.

Google Gemini

This adds policymemo.ai to Gemini as 10 skills. It runs on Google’s models with the same written rules as the Claude version. Expect it to drift from them more, especially over a long conversation.

What you need

  • A Google account with skills in Gemini. Skills are free on personal accounts for people aged 18 and over. On a work or education account, an administrator decides.
  • Gemini on a computer, at gemini.google.com or in the Mac app. Skills cannot be uploaded from a phone.
Download for Gemini

Unzip it first, unlike the Claude version. On Windows, right-click the zip and choose Extract All: opening it with a double-click is not enough. On a Mac, double-click it. Inside, leave the 10 skill zips zipped: Gemini wants those exactly as they are.

Add the skills

  1. Open Gemini and go to Skills.
  2. Choose to upload a skill. Do not use Create with Gemini or Create manually: the first rewrites the skill, and the second only takes a single file, so supporting files would be lost.
  3. Upload each of the 10 zip files in the 1 Upload these 10 skills folder, one at a time. Do not unzip them and do not rename them. policymemo is the front door: it holds the house rules and knows which skill does each job. The other 9 are the capabilities, and each carries the house rules too, so they hold whichever one Gemini picks.
  4. Check all 10 are switched on.

Check it worked

Start a new chat and type /policymemo, then describe a problem you are working on. It should ask you a question back before it writes anything. That is deliberate, the same as the Claude version.

You do not always need the slash. Gemini uses a skill on its own when your message matches it, so describing the problem is often enough.

If it goes wrong

There is no Skills option

Skills are still reaching some accounts. On a work or education account, an administrator may have switched them off. A personal Google account will usually have them.

The upload cannot find the files, or will not take them

You are probably looking inside the download without having unzipped it. Close the upload window, unzip the download as described above, and upload from the folder that appears.

Then upload each policymemo zip file itself. A skill that has been unzipped into a folder may lose its supporting files.

It answers without the method

Gemini decides for itself when a skill applies. Type /policymemo, or the skill for the job, such as /policymemo-evidence, to make sure it is used.

I set up the earlier Gem version

Google is turning Gems into skills from 17 November 2026. Remove the old Gem and add these 10 skills instead, so you do not end up with both.

policymemo.ai has been updated

Updates are not automatic. Download the new zip, remove the old policymemo skills and upload the new ones.

Questions

Is it free?

Yes. Policymemo.ai costs nothing. You need access to the AI tool you install it in: a paid Claude plan for the one-step plugin (the free plan works with the skills added one at a time), Copilot Chat on a work or university Microsoft account, or Gemini with skills switched on.

Which tool should I use?

If you have a choice, Claude. It is the main version and has had the most testing. If your organisation has approved Copilot or Gemini and not Claude, use the one you are allowed to use. They follow the same rules, and drift from them more over a long conversation.

Will my organisation allow it?

None of the routes needs admin rights, but each depends on a setting your organisation controls. Copilot needs agent creation switched on, Gemini skills can be switched off on work and education accounts, and some organisations limit Claude plugins. Whatever tool you use, your organisation’s rules on sensitive and personal data still apply.

Does anything I paste get sent to you?

No. The skills are written instructions with no code in them. There is no policymemo.ai server and no policymemo.ai account, so nothing you paste into a conversation is sent to us or stored by us.

Your conversations are handled by the company behind the tool you use, under the same terms as any other conversation on your plan or your organisation’s agreement. In Copilot and Gemini, the files you upload when you set it up are kept with the agent or Gem in your account.

Your organisation’s rules still apply. If you work with sensitive or personal data, check what your organisation allows in your AI tool before you paste it in.

Will it write the memo for me?

Yes, once the thinking is done. It asks questions first, one at a time, and where a figure is missing it leaves a marked gap rather than inventing one. If you want a document produced without being asked anything, it is the wrong tool.

How do I update or remove it?

A Claude plugin added through the marketplace updates itself. Everything else stays at the version you installed: to update, repeat the steps with the new download. To remove it, switch it off or delete it where you added it.

Tell me when it goes wrong

Say which tool you used, and for Copilot whether you added skills, knowledge files or neither. The most useful thing is the conversation itself: what you were trying to do, and what felt wrong or missing. Remove anything identifying first.
